# Monitoring Plan

## Data Drift
Monitor changes in customer behavior and feature distributions.

## Prediction Distribution
Track percentage of customers predicted as churners.

## Business Outcomes
Measure retention campaign success rate and actual churn.

## API Errors
Monitor response failures and latency.

## Retraining Triggers
Retrain if model performance drops or significant drift is detected.

# Responsible Use

This API should support retention teams in prioritizing outreach.

Predictions should not be used as the sole basis for customer decisions.

Human review is recommended before taking action.
