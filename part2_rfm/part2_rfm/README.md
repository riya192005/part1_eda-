# AI/ML Capstone – Part 2: Customer Segmentation using RFM Analysis

## Project Overview

This project applies RFM (Recency, Frequency, Monetary) analysis to segment customers based on purchasing behavior.

The goal is to identify valuable customer groups and generate actionable business recommendations.

---

## Dataset

File used:

- rfm_modeling_snapshot.csv

---

## RFM Metrics

### Recency
Days since last purchase.

### Frequency
Number of purchases during the previous 180 days.

### Monetary
Total customer spending during the previous 180 days.

---

## Segments Created

- Champions
- Loyal Customers
- Potential Loyalists
- At Risk
- Lost Customers

---

## Business Value

RFM segmentation enables:

- Customer retention strategies
- Personalized marketing campaigns
- Customer lifetime value improvement
- Better allocation of marketing resources
