# AI/ML Capstone – Part 1: Exploratory Data Analysis (EDA)

## Project Overview

This project analyzes customer behavior and churn risk using multiple business datasets. The objective is to identify patterns associated with customer churn and provide business recommendations based on exploratory data analysis.

## Datasets Used

* customers.csv
* orders.csv
* churn_labels.csv
* support_tickets.csv
* intervention_history.csv
* web_events_snapshot.csv

## Files Included

* eda_audit.ipynb – Main exploratory data analysis notebook
* data_quality_report.md – Data quality findings and recommendations
* business_memo.md – Business insights and recommendations
* requirements.txt – Python dependencies

## Key Findings

1. Customers with fewer orders are more likely to churn.
2. Lower-spending customers show higher churn risk.
3. Churn occurs across all age groups and city tiers.
4. Customer support experience may influence churn behavior.
